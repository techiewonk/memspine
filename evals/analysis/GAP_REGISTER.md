# Gap register - LoCoMo, local Qwen stack (2026-10-10)

One list, ordered for discussion. Sources: `RECALL_GAPS_FORENSIC.md` (R), `READER_GAPS_FORENSIC.md` (D),
`ENGINEERING_GAPS.md` (E), earlier `RETRIEVAL_GAPS.md` / `READER_GAPS.md` (simulation era, partly superseded).
Reference run: fixed config `qa-full-qs-eq06-fix`, 80.1% (baseline `qa-full-qs-eq06-roff-fx` 74.5%).
Numbers are MEASURED from stage logs unless marked est.

| # | Gap | Evidence (count) | Why it happens | Solution options | Status |
|---|---|---|---|---|---|
| G1 | **Measurement is not trustworthy enough to tune on** | same 9B model is reader and judge; judge false negatives 24-50 q (D), false positives on partial lists est. 45-60 q (D); 21+ gold-label errors (D); Ollama `presence_penalty 1.5` applied to every call (E SRV-2); think-on result was an Ollama 4096-window artefact (E SRV-1); fixes gained +10.5 on the tuning conversation vs +5.1 elsewhere (E EVAL-4); fix run changed 5 things at once (E HAR-4) | evaluation protocol grew ad hoc | deterministic judge pre-pass (dates, containment); independent second judge on disputed rows; official Mem0 judge prompt alongside; explicit sampler params + context-window assert; dev/held-out split (tune on 4 conversations, report on 6); gold-error exclusion list; paired comparisons with CIs | open |
| G2 | **Category-vs-instance gap (multi-hop lists)** | 164 lost gold turns (32% of losses), 52% of such turns lost; only 50% of multi-hop questions have all gold in any leg (R) | the question names a category ("hobbies"), turns name instances ("kayaking") - no shared words, weak embedding match | LLM query decomposition / planner probes; list cards or mined facts at write time (`mine_facts`, `list_cards`); entity/topic index; est. +18 to +36 multi-hop q (R) | open |
| G3 | **Top-10 fusion cut** | 237 gold turns in a leg's top-30 but outside the fused top-10; 195 of them vector-only (R) | RRF of two legs cut to 10 before anything else; BM25 adds noise (34% of its top-10 share no content word) | candidate pool 30 + rank-tiered window (+90 fully covered q, context ~3.4k tokens, reader-dilution risk); pool 30 + reranker keep 10 (oracle +81, est. 60-80% realisable); leg weights / rrf_k / existing expansions measured neutral or harmful (R) | open |
| G4 | **Reranker deletes hits** | keeps 5.7 of 10 hits; 97.6% of questions lose >=1; 74% of the gold it loses was a window neighbour of a dropped hit; reranker run 70.8% (R, E) | min-max normalised rerank scores + `relative_floor 0.3` | `rerank_floor=skip` (implemented), wider pool + `rerank_keep` (exists), then re-measure | fix ready, untested on full run |
| G5 | **Evidence is not stated literally / needs inference** | 112 gold turns do not literally contain the answer (some weak labels), 96 open-domain turns (R); 23 open-domain read failures (D) | the answer is an implication of the conversation, or world knowledge | derived memory (persona/profile facts, summaries) at write time; reader reasoning (thinking mode, untested - see G1); accept as dataset noise where gold is weak | open |
| G6 | **Gold in sessions with no hit** | 75% of lost gold sits in a session where no turn was retrieved, so no window can reach it (R) | retrieval is turn-level only | session-level index (session digests / summaries) as a leg; two-stage session-then-turn search | open |
| G7 | **Reader picks the wrong line / drops detail** | wrong-line distractor 18, vague detail 16, list incomplete 10 (D); answers shrank 32 -> 18 words while context grew 32%; 49 previously-right answers broke (D) | bigger, flat, chronological context with no marking of which lines were hits; terse prompt | mark or order retrieval hits; window by question type; answer-style clause for lists/detail; est. +12 to +20 q (D) | open |
| G8 | **Date and duration arithmetic** | 13 duration + 3 anchoring failures (D) | the LLM does date maths | deterministic duration annotator and two-event elapsed-time helper; est. +6 to +9 q (D) | open |
| G9 | **Image captions ignored by the reader** | 8 read failures (D); captions do NOT predict retrieval loss (R) | captions appended as "[image: ...]" | prompt note on captions; caption as its own line | open |
| G10 | **Token budget vs context window** | real tokens are 1.12-1.25x the engine count; harness counts 7% higher; harness cuts from the tail; top_k 20 collapsed to 48.7% (E HAR-1) | three different token counters, chronological tail cut | engine assembles to the reader budget with the reader's tokenizer; no tail cut; context window >= 2x budget (set 8192); per-call assert | partly fixed (8192 window) |
| G11 | **Reproducibility and run hygiene** | no server config/versions in manifests; scripts exit 0 on failure; CI never runs evals tests; `uv.lock` gitignored (E) | ad hoc scripts | one run wrapper that fails loudly and records config; CI job for evals tests; commit lock file | open |
| G12 | **Silent failure paths** | firewall quarantine not logged; locale-dependent date parser falls back to "now"; reranker unavailable -> silent skip (E INJ-2/3) | defensive defaults | log quarantine in ingest log; fail on unparsed dates in evals; assert reranker active when configured | open |
| G13 | **Corpus text in git** | 6,476 rows of LoCoMo text committed (E EVAL-9); kept by user decision 2026-10-09 | run outputs committed | revisit if the repo becomes public | decided: keep |
| G14 | **Inference serving** | localhost cost ~2.1 s per plain request (fixed: 127.0.0.1); new HTTP client per call (fixed: pooled); 2 arms on one Ollama slot inflated latency 3.6x (E HAR-6) | Windows IPv6 fallback, serving config | done: 127.0.0.1, pooled client, flash attention, q8 KV, 8192 window; run one heavy arm at a time | fixed |
