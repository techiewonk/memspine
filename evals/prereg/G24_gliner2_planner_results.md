## Reading (hand-written, 2026-10-06)

- **The old options were nearly a constant `retrieve` classifier.** On the held-out questions:
  3/17 count or list questions went to compose, 0/16 replay questions went to replay, and
  median confidence was 1.000. This reproduces the task #42 finding on a labelled set.
- **The label names matter most.** Keeping the old descriptions and only adding rules first
  scores 0.745 on tune. Plain labels (`count or list` / `reason or feeling` / `single fact`)
  with cue-word descriptions score 0.765 without rules. Several things hurt on tune: changing
  the task name from `choice`, hand-written few-shot examples, the label set B
  (`aggregation` / `explanation` / `lookup`), and appending shape hints to the question. The
  hints push replay recall down to 0.12. gliner2 1.3.2's `prompt=` option changes the result
  key, so it was dropped.
- **Selected and shipped: `D + rules first`** (ADR-052). Held-out accuracy is 0.939 against
  0.388 for the old options. On compose and ordering items the hybrid agrees with the labels
  by construction, because the labelling and the hybrid share those predicates. The informative
  column is "accuracy, rule-open items": **0.889** (24/27) against 0.593 for the old options,
  which equals constant `retrieve` on those items. The best single-model setup (`A`) scored
  0.735 overall and 0.852 on the open items.
- **Confidence stays uninformative.** The median is still 1.000, so `planner_min_confidence`
  remains a weak filter for the provider's choices. Rule choices are not gated.
- **`fastino/gliner2-large-v1`, tune half only** (exploration harness: same schema, argmax
  over sigmoid scores, which picks the same label as the shipped call): `A` 0.627,
  `D` 0.667, `D + rules first` 0.843, `C` 0.627. None beat base, so it was not carried to
  held-out. It uses 1.9 GB on disk in `D:/hf-cache`.
- **Engine path check.** `Engine._plan_read_mode` with the real provider on all 100 questions
  matched the script: 48/51 on tune and 46/49 on held-out.
- **Limits.** n = 49 held out, one run, one machine. The labels are a rule proxy, not routing
  gold: some sets are labelled `retrieve` because no rule fires (e.g. "What martial arts has
  John done?"). Downstream answer quality after routing was not measured.
