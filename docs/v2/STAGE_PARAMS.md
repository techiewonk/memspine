# Stage parameter catalogue

Generated by `scripts/build_stage_params.py` from the config schema, the engine source and the harness CLI; machine form in `docs/v2/data/stage_params.json`. Do not edit by hand: curate `docs/v2/data/stage_params_manual.json`.

A key is listed under every stage whose code reads it (AST scan of attribute reads, matched to the file:function of [PIPELINE_STAGE_INVENTORY.md](PIPELINE_STAGE_INVENTORY.md)). `rebuild` says what a change forces when data already exists: `ingest` (re-ingest), `index` (rebuild the vector, lexical or graph index) or `sleep` (re-run the sleep stages); empty means a read-time switch. `effect` is the first sentence of the key's `docs/USAGE.md` description (the `--help` text for CLI flags). Screens are the S-numbers of `evals/v2_queue.tsv` and [SCREENS.md](SCREENS.md) that varied the key (directly or through a profile preset).

Schema keys: 614; not attributed to any stage: 131 (listed at the end).
